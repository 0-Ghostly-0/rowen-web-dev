# Taste Calibration

The goal is not maximum decoration. The goal is a coherent interface that feels inevitable for this product.

## Establish a taste brief
For substantial visual work, privately summarize:
- 3–5 adjectives the interface should embody;
- 3 things it must not feel like;
- the strongest visual hierarchy decision;
- the typography role;
- the density level;
- the material/texture level;
- the one memorable detail worth protecting.

Use the existing product as the strongest reference when it already has a good identity.

## Visual hierarchy
Run the squint test: at a glance, the intended primary action/content should dominate, secondary content should group naturally, and tertiary information should recede.

Do not use borders/cards/backgrounds to solve hierarchy that typography, spacing and grouping could solve more cleanly.

## Restraint
A distinctive site usually needs a few strong decisions, not every possible effect.

If everything is:
- rounded, nothing feels especially soft;
- glass, glass stops feeling special;
- animated, motion loses meaning;
- accented, hierarchy disappears;
- oversized, nothing has emphasis.

## Anti-template comparison
Before finishing, ask:
- Could the product name/logo be swapped with an unrelated startup without changing the design?
- Does the hero use the same composition Claude would likely generate for ten other products?
- Are cards being used because the information needs containment, or because cards are easy?
- Is the palette recognizable without the logo?
- Does typography contribute personality?
- Is there at least one product-specific interaction/composition/detail?

If the design is interchangeable, revisit the art direction rather than adding decoration.

## Preserve what works
A design review must identify strengths as well as defects. Do not “improve” distinctive existing decisions into generic consistency.
