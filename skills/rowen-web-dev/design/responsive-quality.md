# Responsive Quality

Responsive design is content-driven, not device-preset-driven.

- Introduce breakpoints when hierarchy, readability, navigation or task completion breaks.
- Prefer flexible Grid/Flex/container behavior before fixed positioning/dimensions.
- Define wrapping, stacking, truncation and overflow behavior.
- Test narrow, wide, high zoom and large text.
- Dense tables need intentional overflow, column priority or an alternate presentation.
- Sticky/fixed UI must not hide content or focused controls.
- Do not merely shrink desktop UI onto mobile.
