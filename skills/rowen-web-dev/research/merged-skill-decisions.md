# Merged Skill Decisions

Useful behaviors were synthesized from external skills rather than copied wholesale.

Included:
- Anthropic frontend-design: subject-matter-grounded art direction, intentional differentiation, consistent user-facing vocabulary.
- obra/superpowers: root-cause-first debugging and evidence-before-completion.
- NearForm Lastlight: rendered browser QA and evidence.
- AppSec project assessment: choose security checks from actual stack/data/attack surface.
- mgifford accessibility skills: feature-specific accessibility checks, especially forms.
- hueyexe frontend skills: complete interaction/data states and UX writing as part of interaction design.
- magnus919 frontend engineering: state/API/responsive/performance concerns as engineering responsibilities.
- jezweb design-system/design-loop: capture project visual language to avoid drift.
- Google/MDN/web.dev principles already present: prefer current platform guidance.

Intentionally not imported:
- mandatory TDD for every styling/configuration change;
- aesthetic bans treated as universal law (for example, never using a common font);
- animation for spectacle when it conflicts with Rowen's preference for clean restrained motion;
- generic architecture complexity;
- rules unsupported by current standards or the actual project.
