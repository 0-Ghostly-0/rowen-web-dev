# Browser Finish Pass

1. Render the actual interface.
2. Check representative narrow and wide viewports.
3. Tab through the changed surface.
4. Trigger applicable loading, empty, no-results, validation, network/server error, success, disabled and permission states.
5. Test long content and missing values.
6. Test dialog/drawer focus, Escape, scrolling and mobile behavior.
7. Test forms for invalid submission, retained values, autofill semantics and duplicate-submit protection.
8. Test uploads for drag feedback, invalid file, progress, partial batch failure, retry/remove and slow-network behavior when supported.
9. Test mutations with delay, double-click and failure/recovery.
10. Check console/runtime errors.
11. Check reduced motion where animation matters.
12. Fix implementation defects before completion.
