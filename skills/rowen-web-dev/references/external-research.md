# External Research & Skill Patterns

Sources used as inspiration/evidence, not templates to copy:

- W3C WCAG 2.2: accessibility, focus, target size, errors, status messages.
- MDN Web Docs: current browser/platform behavior and compatibility.
- web.dev/Core Web Vitals: loading, responsiveness and visual stability.
- Nielsen Norman Group: visibility of system status, user control/freedom, error prevention.
- OWASP Cheat Sheet Series/ASVS: application security.
- Next.js, React, Vercel and Stripe official docs.
- StoryScope (Russell et al., 2026), cautiously adapted through HumanScope for writing.
- Anthropic Claude Code frontend-design skill: deliberate art direction rather than template defaults.
- PracticalSwan/agent-skills frontend-design: complete states, accessibility hard gates, resilience, measurable performance, rendered verification.
- GoogleChrome/modern-web-guidance: retrieve current platform guidance instead of relying on stale web-platform memory.
- magnus919/agent-skills: task-oriented accessibility, complete data states and performance as UX.
- hueyexe/frontend-agent-skills UX writing: microcopy as part of interaction/recovery.
- nearform/lastlight browser-qa: rendered QA with evidence.
- jezweb/claude-skills design-system: extract an existing product's visual language before generating more UI.
- mgifford/accessibility-skills forms: validation, recovery, autofill, password managers, keyboard and assistive technology.

Rule: third-party skills are prompts for investigation, not authority. Prefer current official standards/docs and established research when rules conflict.
