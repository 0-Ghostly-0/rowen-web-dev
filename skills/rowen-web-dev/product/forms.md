# Forms and Checkout Quality

Forms should minimize effort and preserve trust.

- Use visible, associated labels.
- Ask only for information actually needed.
- Use semantic input types, autocomplete and input modes.
- Explain constraints before submission when useful.
- Validate near the source without aggressively interrupting typing.
- On failure, preserve valid input and clearly identify fields needing attention.
- Focus/announce errors appropriately.
- Prevent duplicate submission while pending.
- Show success in context and explain what happens next.
- Support password managers/autofill where relevant.
- Never disable paste for credentials/codes without a compelling reason.
- For checkout, make price, recurrence, fees, cancellation/refund expectations and final action clear before commitment.

Server-side validation remains authoritative.
