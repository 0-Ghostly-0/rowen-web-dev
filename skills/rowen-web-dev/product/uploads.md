# Uploaded Video: Upload UX Lessons

The supplied video demonstrates five small but meaningful upload-quality patterns:

1. Drag feedback: a drop target visibly responds while a file is dragged over it.
2. Honest progress: measurable uploads show real progress rather than an indefinite spinner; useful context can include percent, defensible ETA, or transfer rate.
3. Inline retry/resume: connection failure should keep the file/work loaded and resume from the last safe point when technically feasible.
4. Upload preview: for visual media, show a thumbnail/preview plus filename, type and size rather than only a text confirmation.
5. Independent queue: each file has its own state; one failed file should not erase completed files.

General principle: acknowledge input, expose meaningful state, preserve completed work, show proof of what happened, isolate failures, and provide recovery. Apply the same thinking to imports, exports, renders, saves, AI jobs, payments, and bulk admin actions.
